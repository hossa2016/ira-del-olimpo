# Ira del Olimpo

Juego de acción 3D con mitología griega (cuatro mundos: Tebas, el Laberinto de Creta, el Inframundo y el Olimpo).

- El juego está en `app/src/main/assets/www` y funciona sin internet.
- Cada cambio en `main` compila el APK automáticamente con GitHub Actions y lo publica en **Releases**.
- Modelos y animaciones: Quaternius (CC0). Motor: three.js (MIT).
